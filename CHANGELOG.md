## 0.1.0

First release.

- Theme: Kumo's 54 semantic color tokens for light and dark and the FedRAMP theme, converted from Kumo's OKLCH CSS with CSS Color 4 gamut mapping. `KumoThemeProvider`, `context.kumo`, Material bridge, mode cross-fade.
- Tokens: Tailwind 4px spacing, radii, shadows, rings, breakpoints; Inter and JetBrains Mono on Kumo's type scale.
- Icons: 1,530 Phosphor icons in regular and fill weights (`KumoIcons`), plus a searchable catalog library.
- Motion: springs from the current value (`KumoMotion`, `KumoSprings`), press feedback on every pressable, sheets that follow the finger, popups that scale from their trigger, reduced motion everywhere.
- Components: forms, controls, selection, menus and popovers, navigation, dialogs and toasts, data, display, dates and time, charts, flow diagrams, the responsive app shell and Kumo's blocks (page header, resource list, delete resource).
- Localizable built-in copy through `KumoStrings` and `KumoLocale`.
- Agent skills (`dart run kumo_flutter:install_skill`), `llms.txt`, and a reference page for every component.
